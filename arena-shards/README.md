# Арена Осколков

Мобильный автобаттлер по дизайн-документу «Арена Осколков»: два ряда стола, руны на клетках,
цикл День/Сумерки/Ночь, Пробуждение и Контракты. В этой реализации матч всегда играется **против
ботов** — онлайн-сервер из документа (раздел 7) не реализован, но всё игровое ядро (таверна, бой,
существа, руны, герои, контракты) работает полностью на устройстве, поэтому игра доступна офлайн.

## Боты и сложность (в духе Stronghold Crusader)

При старте матча выбирается сложность соперников — пять ступеней, как ряд лордов в осадной миссии,
от новичка до безжалостного стратега (`packages/core/src/bots.ts`):

| Сложность | Поведение |
|---|---|
| **Крестьянин** | Покупки и ходы почти случайны, таверну почти не улучшает |
| **Ополченец** | Заполняет стол, изредка улучшает таверну, не считает синергию племён |
| **Разбойник** | Оценивает существ по силе/племени, следует простому графику улучшений, покупает руны |
| **Полководец** | Строит состав вокруг синергии племён, управляет контрактами и рядами |
| **Владыка Осколков** | Прогоняет пробные бои перед решением и не оставляет золото/Осколки без дела |

Также можно выбрать «Смешанную» сложность — тогда лобби ботов выстраивается лестницей от
Крестьянина до Владыки, как отряд разных по силе противников.

## Структура репозитория

```
arena-shards/
  packages/core/     # игровое ядро: TypeScript, чистые функции, детерминированный RNG (mulberry32)
    src/types.ts      # типы существ, рун, героев, состояния матча
    src/data/*.json    # 40 существ, 8 рун, 10 героев, 6 контрактов из дизайн-документа
    src/tavern.ts      # таверна, пул существ, слияние
    src/combat.ts      # симуляция боя (два ряда, ключевые слова, очередь смертей)
    src/match.ts       # applyAction, ходы, подбор пар, урон, контракты
    src/bots.ts        # ИИ-боты пяти уровней сложности
    test/              # Vitest: экономика, слияние, бой, детерминизм, полный матч
  apps/client/        # мобильный веб-клиент: React + Vite, адаптирован под телефон
    src/screens/       # экран выбора (герой/сложность), экран матча, экран результатов
    android/, ios/     # нативные проекты Capacitor (обёртка веб-клиента)
```

## Запуск

```bash
pnpm install
pnpm test          # юнит-тесты ядра (Vitest)
pnpm dev           # веб-клиент на http://localhost:5173 (открывайте с телефона в локальной сети)
pnpm build         # прод-сборка ядра и клиента
```

## Сборка мобильного приложения (Capacitor)

Веб-клиент уже обёрнут в нативные проекты Android/iOS (`apps/client/android`, `apps/client/ios`).
Чтобы собрать APK/IPA после изменений в клиенте:

```bash
cd apps/client
pnpm run cap:sync          # пересобирает веб-клиент и копирует его в android/ и ios/
pnpm run cap:open:android  # открывает проект в Android Studio
pnpm run cap:open:ios      # открывает проект в Xcode (нужен macOS)
```

Дальше — обычная сборка/подпись/публикация через Android Studio или Xcode.

## Известные упрощения

Документ (раздел 8) явно допускает выбирать простейшую трактовку неоднозначных правил и помечать
допущения. Основные упрощения в этой реализации:

- Нет онлайн-сервера/подбора живых игроков (раздел 7.2–7.9) — только локальный матч против ботов.
- Ауры (например, Связь, эффекты Голоса Рощи) пересчитываются один раз в начале боя, а не при
  каждом изменении стола.
- «Древний Топлец» (призыв копий двух последних погибших существ Топи) упрощён: история последних
  погибших по всему матчу не отслеживается отдельно.
- Оценка ходов ботом «Владыка Осколков» использует несколько пробных боёв (а не 200), чтобы решения
  оставались мгновенными на мобильном устройстве.
