# SAI2 Recovery

Программа для Windows, которая восстанавливает повреждённые файлы **PaintTool SAI Ver.2 (`.sai2`)**:
проверяет файл, исправляет структуру, спасает уцелевшие слои и сохраняет всё, что удалось прочитать,
в обычные форматы.

- **Исходный файл не изменяется.** Результат кладётся в папку `<имя>_восстановление` рядом с файлом.
- В результате: исправленный `…_восстановлен.sai2`, сведённое изображение и каждый слой в PNG,
  `слои.ora` (все слои одним файлом для Krita, GIMP, MyPaint) и `отчёт.txt`.
- Есть поиск копий и фрагментов SAI2 по содержимому, а не по имени.
- Устанавливается установщиком: ярлыки, пункт «Восстановить в SAI2 Recovery» в контекстном меню
  проводника для `.sai2`, по желанию консольная утилита `sai2fix` в PATH.

## Установка

Скачайте `SAI2Recovery-Setup-<версия>.exe` из раздела **Releases** или из артефактов последней
сборки в **Actions → Build installer**. Нужна 64-битная Windows 10 или 11. .NET отдельно ставить
не надо: он встроен в программу. Права администратора не требуются: установщик предложит поставить
программу только для текущего пользователя.

Для работы без установки есть `SAI2Recovery-portable-<версия>.zip`.

## Как пользоваться

1. Перетащите повреждённые `.sai2` в окно программы или выберите их через «Добавить файлы…».
   Можно перетащить целую папку.
2. Программа сразу проверит каждый файл: покажет превью, размер холста и что именно повреждено.
3. Нажмите **«Восстановить выбранные»**. Когда восстановление закончится, откроется папка с результатом.
4. Откройте `…_восстановлен.sai2` в SAI2. Если SAI2 его не откроет, возьмите `слои.ora` или PNG.

Консольный вариант:

```
sai2fix analyze рисунок.sai2           проверить, ничего не меняя
sai2fix repair  рисунок.sai2 -o папка  восстановить
sai2fix scan    D:\Рисунки --deep      найти SAI2 по содержимому
sai2fix carve   образ_диска.img        извлечь все SAI2 из файла
```

## Алгоритм восстановления

Подробно: [docs/ALGORITHM.md](docs/ALGORITHM.md). Описание формата: [docs/SAI2-FORMAT.md](docs/SAI2-FORMAT.md).

Кратко:

1. **Поиск заголовка.** Сначала по сигнатуре `SAI-CANVAS-TYPE0`, в том числе если перед ней есть мусор.
   Если сигнатура испорчена, но структура за ней правдоподобна, сигнатура восстанавливается.
   Если файл целиком из нулей или пустой, программа честно сообщает, что данных нет, и подсказывает,
   где искать копии.
2. **Таблица блоков.** Число записей проверяется тремя способами: по заголовку, по смещению первого
   блока и по самим записям. Если у записи испорчено смещение, блок ищется сразу за концом предыдущего:
   размер слоя и пиксельных данных вычисляется точно, разбором. Если испорчен тип, он определяется по
   содержимому блока. Записи, указывающие за конец файла, означают, что файл обрезан.
3. **Глубокое сканирование**, если начало файла затёрто. Весь файл просматривается на сигнатуры
   `layr`, `dpcm` и `jssf`. Каждый кандидат проверяется полным разбором, и из найденных блоков
   таблица строится заново.
4. **Размер холста** восстанавливается по сведённому изображению. Сетка плиток видна по их заголовкам,
   а точная ширина и высота находятся перебором: побайтно точный кодек «сходится» только на верном размере.
5. **Проверка пикселей.** Каждая плитка 256×256 каждого слоя декодируется полностью. Если плитка
   повреждена, её читаемые строки сохраняются. Плитки, потерянные из-за обрезки, становятся прозрачными,
   а число плиток слоя остаётся прежним.
6. **Сборка нового файла.** Исправленный заголовок, новая таблица, блоки идут подряд. Целые данные
   копируются байт в байт. Слой без описания или без пикселей удаляется, чтобы SAI2 смог открыть
   остальное. Повреждённую историю и миниатюру SAI2 создаст заново.
7. **Повторная проверка** собранного файла тем же анализатором и **экспорт** всего читаемого
   в PNG и ORA.

## Ограничения

Формат SAI2 закрыт. Программа опирается на неофициальную спецификацию
([photopea/SAI2-specification](https://github.com/photopea/SAI2-specification)) и на декодер из
[libsai](https://github.com/Wunkolo/libsai). Декодер плиток перенесён один в один и сверен с
оригиналом на эталонных данных (`tools/crosscheck`).

- Служебные блоки (история, линии, фигуры, текст, линейки) копируются без проверки содержимого,
  а повреждённые удаляются.
- Повреждение внутри плитки не всегда видно с точностью до строки. Если плитка испорчена случайными
  байтами, а не нулями и не обрывом, строки после места повреждения могут выглядеть как шум.
- Тестировалось на синтетических файлах, построенных по спецификации. Если какой-то файл
  восстановился неправильно, приложите `отчёт.txt` к issue.

## Сборка

Нужен .NET SDK 10.

```
dotnet test tests/Sai2Recovery.Tests
dotnet publish src/Sai2Recovery.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish/app
dotnet publish src/Sai2Recovery.Cli -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:PublishTrimmed=true -o publish/cli
"%ProgramFiles(x86)%\Inno Setup 6\ISCC.exe" installer\Sai2Recovery.iss
```

Установщик собирается автоматически при каждом push (GitHub Actions, `.github/workflows/build.yml`).
При push тега `v*` создаётся релиз.

Структура:

| Папка | Что внутри |
|---|---|
| `src/Sai2Recovery.Core` | формат, кодеки, анализатор, восстановление, экспорт, поиск копий |
| `src/Sai2Recovery.App` | оконная программа (WinForms) |
| `src/Sai2Recovery.Cli` | консольная утилита `sai2fix` |
| `tests/Sai2Recovery.Tests` | тесты: эталоны libsai и сценарии повреждений |
| `tools/crosscheck` | сверка кодека с оригинальным libsai, генерация эталонов |
| `installer` | скрипт Inno Setup |
